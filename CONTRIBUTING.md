# Contribuyendo a AL100

Gracias por tu interés en contribuir a AL100.

## Cómo contribuir

1. Haz fork del repositorio
2. Crea una rama para tu feature (`git checkout -b feature/amazing-feature`)
3. Haz commit de tus cambios (`git commit -m 'feat: add amazing feature'`)
4. Haz push a la rama (`git push origin feature/amazing-feature`)
5. Abre un Pull Request

## Convenciones

- Usa conventional commits para los mensajes de commit
- Sigue el estilo de código existente
- Asegúrate de que los tests pasen antes de abrir un PR
- Mantén los PRs pequeños y enfocados

## Reportar Issues

Usa el tracker de issues de GitHub para reportar bugs o sugerir features.
